# AfriConnect Summit 2026

Site vitrine complet pour une conférence tech panafricaine fictive, réalisé dans le cadre de l'examen de Technologie Web.

**Auteur :** [yaye oumy khairy dieng]
**Classe :** [L1 IAGE]

## Description du projet

AfriConnect Summit est un site événementiel fictif réunissant développeurs, entrepreneurs et investisseurs du continent africain. Le site comprend 4 pages : Accueil, Programme, Intervenants et Contact/Inscription, avec une navigation cohérente, un dark mode persistant et des interactions JavaScript sur l'ensemble des pages.

## Technologies utilisées

- **HTML5** — structure sémantique (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** — variables CSS, Flexbox, Grid, animations, transitions, responsive design (media queries)
- **JavaScript vanilla** — manipulation du DOM, IntersectionObserver, localStorage, validation de formulaire
- **Google Fonts** — Sora (titres) et Manrope (corps de texte)
- **Bootstrap Icons** — icônes via CDN
- **Git & GitHub** — versioning et déploiement via GitHub Pages

## Fonctionnalités JavaScript implémentées

1. Dark Mode / Light Mode avec persistance via `localStorage`
2. Navbar dynamique au scroll + menu hamburger mobile
3. Animations fade-in au scroll via `IntersectionObserver`
4. Onglets du programme (affichage des 3 jours sans rechargement)
5. Filtrage dynamique des intervenants par thématique
6. Validation complète du formulaire d'inscription (regex email, téléphone, longueur du message)
7. Bouton retour en haut avec défilement fluide
8. Année dynamique dans le footer (`new Date().getFullYear()`)
9. Compteurs animés au scroll (statistiques de l'accueil)
10. Compte à rebours en temps réel jusqu'à la date de la conférence
